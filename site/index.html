A capability token carries a fingerprint of tool, identity, arguments
    and the targets the kernel itself derived. A different path is a different token. A forgotten
    gate call is not an unchecked effect — it is no effect at all.

§3
Provenance of the name

    

      

        
The giant had one vein, closed by a single nail.

        
Talos was a giant of bronze. Three times a day he circled Crete and let nothing ashore
        that did not belong there.

        
He is not remembered because he was strong. He is remembered because someone
        could stop him — and knew where. Most agents build the strength first and the
        brake afterwards. This one was built the other way around.

      

      

        

          
/stopHalts immediately. No model, no thinking round.

          
/undoTakes back the last action wherever it can be.

          
/autonomy 0Invalidates even rights already in flight.

          
/logWritten before the effect, not after.

        

        
A brake that has to think first is not a brake. These four run
        deterministically, with no language model in between.

§4
Known limits

    
A security claim without its limits is marketing — these are ours, stated first

    
    
      
  • The shell needs a sandbox the platform can provide. bubblewrap on Linux,
      sandbox-exec on macOS. Where neither exists it refuses rather than running unprotected.
    • 
      
  • It is not a multi-tenant security boundary. One operator, one machine.
    • 
      
  • It does not defend against a malicious model. It defends against a mistaken
      one, and against injection arriving through tool output. Different threats.
    • 
      
  • Every way in has to fetch, never receive. Telegram long-polls, mail is
      pulled over IMAP — nothing opens a listening socket. A From: header is only a
      claim; unauthenticated mail is dropped rather than trusted.
    •
